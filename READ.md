3️⃣ What is the difference between map(), filter(), and forEach()?
answer-->

1️⃣ map()
Array-এর প্রতিটি element এর উপর কাজ করে নতুন array return করে।

2️⃣filter()-
Array থেকে condition অনুযায়ী element বেছে নেয়। নতুন array return করে।

3️⃣ forEach()-
Array-এর প্রতিটি element এর উপর loop চালায়। কিন্তু কিছু return করে না।
